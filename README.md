**Xiaomi Watch Thermometer v2.0** — автономное нативное приложение для смарт-часов **Xiaomi Watch 5** (и других часов на Wear OS), превращающее часы в полноценную портативную термографическую станцию с голосовым ассистентом, измерением на виске/лбу, журналом истории и анализом сосудистого тонуса.

## ⚡ Новые возможности (v2.0.0 "WOW" Edition)

### 1. 🗣️ Голосовой ассистент (TTS) через динамик часов
- Озвучивает результаты замера естественным русским голосом (*«Температура тридцать шесть и шесть. В пределах нормы!»* или предупреждает о жаре/переохлаждении).
- Кнопка быстрого отключения/включения звука (`[🔊]` / `[🔇]`) в шапке экрана.
- Кнопка повторного воспроизведения замера прямо рядом с цифрами.

### 2. 🎯 Экспресс-замер на виске / лбу (15 сек)
- Режим измерения височной артерии: достаточно приложить тыльную сторону часов к виску или центру лба.
- Тактильные микро-вибрации (haptic ticks) каждую секунду для ощущения контакта.
- Физиологическая формула расчета ядра тела ($T_{body} = T_{temple} + 0.35^\circ\text{C} + \text{offset}$) с повышенной точностью.

### 3. 🌿 Тепловой баланс и сосудистый индекс ($\Delta T = T_{skin} - T_{ambient}$)
- Оценивает разницу между температурой кожи и окружающим воздухом.
- Диагностика сосудистых состояний:
  - **$\Delta T < 5^\circ\text{C}$**: `❄️ Спазм сосудов` (озноб, синдром холодных рук/ног при стрессе или начале лихорадки).
  - **$5 \dots 12^\circ\text{C}$**: `🌿 Оптимальный тонус сосудов` (нормальная терморегуляция).
  - **$\Delta T > 12^\circ\text{C}$**: `🔥 Активная теплоотдача` (жар, физическая нагрузка, расширенные капилляры).

### 4. 📜 Встроенный журнал и тренд изменений (History Log)
- Автоматически сохраняет последние 12 замеров прямо в памяти часов (`SharedPreferences`).
- Показывает тип замера (`[Рука]`, `[Висок]`, `[Воздух]`), время (*«Только что»*, *«15 мин назад»*, время) и дельту к предыдущему значению ($\uparrow / \downarrow / =$) с цветовой индикацией.
- Кнопка мгновенной очистки журнала.

### 5. ⌚ Вывод на любой циферблат (Wear OS Complications)
- Полноценная поддержка системных усложнений циферблатов Wear OS!
- Поддерживает типы: `SHORT_TEXT` (`36.6°`), `RANGED_VALUE` (прогресс-бар), `ICON` и `LONG_TEXT`.
- Тап по виджету на циферблате сразу открывает приложение на часах.

### 6. 📈 Живой сглаженный график (Sparkline Canvas)
- Отрисовка кривой температуры в реальном времени с кубическими сплайнами Безье.
- Автоматический расчет метрик сессии: **Мин / Среднее / Макс**.

### 7. 👑 Поддержка аппаратного колесика (Rotary Crown)
- Прокручивайте весь длинный список экранов и графиков поворотом физической головки часов с тактильной вибро-отдачей щелчков.

### 8. 🎛️ Точная калибровка и защита от перегрева
- Калибровочный офсет $\pm 2.0^\circ\text{C}$ с шагом $0.1^\circ\text{C}$ для точной подгонки под медицинский ртутный/инфракрасный термометр.
- Баннер защиты от ложных замеров при нагреве батареи на зарядке выше 42 °C.

## ❓ Сможет ли любой человек использовать на Xiaomi Watch 5?

**ДА, абсолютно любой владелец Xiaomi Watch 5 сможет установить и использовать приложение!**

1. **Не требуется Root-прав**, разблокировки загрузчика или модификации прошивки часов.
2. **Аппаратная база идентична:** у всех Xiaomi Watch 5 присутствуют необходимые термодатчики и системные интерфейсы Wear OS.
3. **Установка занимает 2 минуты:** выполняется через стандартную функцию Android — **«Отладку по Wi-Fi»**.

### Совместимость с устройствами:
| Устройство | Совместимость | Примечание |
|---|---|---|
| **Xiaomi Watch 5** |  **100% Идеальная** | Полная оптимизация под сенсоры и коронку |
| **Xiaomi Watch 2 / 2 Pro** |  **100% Полная** | Платформа Wear OS |
| **Любые часы Wear OS (Android 8.0+)** |  **Совместимо** | Samsung Galaxy Watch, Pixel Watch, TicWatch |
| *Xiaomi Watch S3 / S1 / Band* |  *Не поддерживается* | Работают на HyperOS Vela / FreeRTOS (не поддерживают APK) |

## 🚀 Установка

Готовый подписанный файл находится в папке [`release/WatchThermometer.apk`](release/WatchThermometer.apk).

### Шаг 1. Включите отладку на часах (один раз)
1. На часах откройте **Настройки** ➔ **Об устройстве** (или *Система* ➔ *О часах*).
2. Нажмите на **«Номер сборки»** 7 раз подряд до надписи *«Вы стали разработчиком»*.
3. Вернитесь в **«Для разработчиков»** и включите:
   - **Отладка по ADB** (ADB debugging)
   - **Отладка по Wi-Fi** (Wireless debugging)
4. Запомните IP и порт часов (например, `192.168.1.57:5555`).

### Шаг 2. Установка через ADB (с ПК или телефона)
Выполните команду в терминале:
```bash
adb connect <IP_ЧАСОВ>:5555
adb install -r release/WatchThermometer.apk
```

## ⌚ Как вывести температуру на циферблат (Complication):
1. На главном экране часов зажмите палец на текущем циферблате на 2 секунды.
2. Нажмите кнопку **«Настроить»** (Кастомизация).
3. Коснитесь любого круглого или строчного слота.
4. В списке приложений выберите **«Термометр»**.

## 🛠️ Сборка из исходников

Проект собирается без тяжелых Gradle-демонов с помощью легкого python-скрипта на стандартном Android SDK:
```bash
python build.py
```
Скрипт автоматически находит Android Build Tools (AAPT2, D8, ZipAlign, Apksigner), компилирует ресурсы и Java 8 код, упаковывает DEX и подписывает релизный APK размером ~81 КБ.
