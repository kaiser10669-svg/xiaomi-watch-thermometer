**Xiaomi Watch Thermometer v3.0** — автономный медицинский и бытовой термографический комбайн для смарт-часов **Xiaomi Watch 5** (и любых часов на Wear OS). Сочетает функции клинического термометра, анализатора воды и детской ванны, советника по лихорадке с таймером жаропонижающих, экспортом протоколов для врача и классическим ртутным столбиком.

## ⚡ Все возможности приложения

### 1. 🌊 Режим «ВОДА / ВАННА» (Water & Bath Thermometer)
- **Использует влагозащиту 5 ATM** часов Xiaomi Watch 5.
- Вода проводит тепло в 25 раз быстрее воздуха, поэтому замер занимает всего **10 секунд**!
- Автоматическая оценка комфорта воды с голосовым ассистентом:
  - `< 15.0°C`: 🧊 `Ледяная купель (Моржевание)`
  - `15.0 – 28.5°C`: 🏊 `Бодрящая вода (Бассейн)`
  - `28.6 – 35.9°C`: 🌊 `Приятная тёплая вода`
  - `36.0 – 38.5°C`: 👶 `Идеально для детской ванны!`
  - `38.6 – 41.5°C`: ♨️ `Горячая релакс-ванна`
  - `> 41.5°C`: 🔥 `Опасность ожога! Слишком горячо!`

### 2. 🌡️ Анимированный классический ртутный столбик (MercuryGaugeView)
- Стильный стеклянный капилляр и колба с ртутью на чистом аппаратно-ускоренном 2D Canvas.
- Шкала от 34.0°C до 42.0°C с микро-делениями.
- **Золотая отметка 36.6°C** со стрелочкой (культовый визуальный ориентир медицинских термометров).
- Плавная физическая анимация подъема столбика.

### 3. 🩺 Советник при температуре & Таймер жаропонижающих (Fever Advisor & Med Timer)
- Автоматически диагностирует состояние: гипотермия, норма, субфебрилитет, умеренная или высокая лихорадка с понятными клиническими советами.
- **Встроенный таймер приема лекарств**:
  - Быстрый запуск интервала: `+4 часа` (Парацетамол) или `+6 часов` (Ибупрофен).
  - Предотвращает случайную опасную передозировку жаропонижающих.
  - Живой обратный отсчет на экране и в памяти часов.

### 4. 📋 Экспорт отчета для врача (Doctor Clinical Report)
- Одной кнопкой формирует структурированный протокол с пиковыми значениями, средними показателями и журналом замеров.
- Файл сохраняется прямо в `/sdcard/Download/medical_temp_report.txt` и готов к отправке доктору в Telegram, WhatsApp или при визите в поликлинику.

### 5. 🎯 Экспресс-замер на виске / лбу (15 секунд)
- Замер височной артерии с секундным тактильным вибро-пульсом (`Haptic Tick`) и автоматической коррекцией артериального кровотока.

### 6. 🗣️ Голосовой ассистент (TTS)
- Озвучивает замеры тела и воды через встроенный динамик часов на русском языке.
- Кнопка выключения звука `[🔊] / [🔇]` в шапке экрана и кнопка повтора замера.

### 7. 🌿 Тепловой баланс сосудов ($\Delta T = T_{кожи} - T_{воздуха}$)
- Распознает спазм периферических сосудов (озноб/холодные конечности) или активную теплоотдачу при жаре.

### 8. ⌚ Вывод на любой циферблат (Wear OS Complications)
- Полноценный Complication Provider: температура прямо на главном экране часов в любимом циферблате.

### 9. 👑 Аппаратная коронка (Rotary Crown)
- Плавная прокрутка всех экранов и длинных графиков колесиком часов с приятными тактильными щелчками.

## 🚀 Установка

Готовый подписанный файл находится в папке [`release/WatchThermometer.apk`](release/WatchThermometer.apk).

### Шаг 1. Включите отладку по Wi-Fi на часах (один раз)
1. В настройках часов: **Система** ➔ **О часах** ➔ нажмите **Номер сборки** 7 раз.
2. В появившемся меню **Для разработчиков** включите:
   - **Отладка по ADB**
   - **Отладка по Wi-Fi** (появится IP адрес, например: `192.168.1.57:5555`).

### Шаг 2. Установка через консоль (ПК или телефон)
```bash
adb connect <IP_ЧАСОВ>:5555
adb install -r release/WatchThermometer.apk
```
