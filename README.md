**Xiaomi Watch Thermometer** — автономное нативное приложение для смарт-часов **Xiaomi Watch 5** (и других умных часов на Wear OS), измеряющее и рассчитывающее температуру кожи, окружающего воздуха и компонентов часов в режиме реального времени.

## ⚡ Особенности

- **Вывод на любой циферблат (Wear OS Complications):** Поддержка системных усложнений циферблата! Выводите температуру кожи (`33.5°`) или шкалу-диапазон прямо на ваш любимый циферблат. При тапе по значку на циферблате сразу открывается подробный экран приложения.
- **Режим целенаправленного замера («Градусник»):** Кнопка «Начать замер» с 30-секундным таймером прогрева датчика от кожи, тактильной вибрацией при старте/финише и фиксацией результата с оценкой нормы (`✓ В норме`, `⚠ Субфебрильная`, `🔥 Повышенная`).
- **Живой график динамики (Sparkline Canvas):** Наглядная сглаженная кривая Безье в реальном времени с подсчетом Мин / Средн / Макс температуры за сессию.
- **Поддержка физического колесика часов (Rotary Crown):** Плавная прокрутка экрана вращением коронки с тактильными микро-щелчками вибрации (Haptic Ticks).
- **Режим «Воздух / Микроклимат помещения»:** Вкладка для оценки температуры в комнате или на улице без влияния тепла руки.
- **Переключатель единиц измерения:** Быстрое переключение между **°C** и **°F**.
- **Точная калибровка смещения ($\pm 2.0^\circ\text{C}$):** Кнопки подстройки под показания личного медицинского термометра.
- **Защита от перегрева:** Автоматическое предупреждение при нагреве батареи выше 42 °C на зарядке или солнце.
- **Полная автономность:** Приложение работает прямо на часах, не требует постоянного подключения к телефону, интернету или сторонним серверам.
- **Мультисенсорный алгоритм (Thermal Fusion):**
  - **Датчик окружающего воздуха:** считывает физический терморезистор платы/барометра (`Sensor.TYPE_AMBIENT_TEMPERATURE` / Type 13).
  - **Датчик аккумулятора:** считывает температуру контроллера питания (`BatteryManager`).
  - **Прямой сенсор кожи (Goodix Skin Temp):** поддержка прямого OEM-сенсора и термальных зон ядра Linux (`/sys/class/thermal`).
  - **Алгоритм компенсации градиента:** вычисляет реальную температуру запястья и оценочную температуру тела с учетом теплопередачи титаново-керамического корпуса часов.
  - **Компенсация зарядки:** автоматически определяет состояние зарядки и фильтрует нагрев батареи.
  - **Детектор ношения:** определяет, надеты ли часы на руку или сняты («Наденьте часы плотно на руку»).
- **Экстремально легкий (~21 КБ):** Написан на чистом Android SDK без раздутых библиотек Jetpack/Compose. Запускается мгновенно и не расходует память.
- **Энергоэффективный AMOLED-интерфейс:** Глубокий черный фон экономит заряд батареи часов.

## ❓ Сможет ли любой человек использовать на Xiaomi Watch 5?

**ДА, абсолютно любой владелец Xiaomi Watch 5 сможет установить и использовать приложение!**

1. **Не требуется Root-прав**, разблокировки загрузчика или модификации прошивки часов.
2. **Аппаратная база идентична:** у всех Xiaomi Watch 5 присутствуют необходимые термодатчики и системные интерфейсы Wear OS.
3. **Установка занимает 2 минуты:** поскольку в официальном магазине Mi Fitness нет кнопки «загрузить сторонний APK», установка на любые часы Wear OS выполняется через стандартную функцию Android — **«Отладку по Wi-Fi»** (один раз включить в настройках разработчика). Сделать это можно как с компьютера в один клик, так и прямо со смартфона без ПК.

### Совместимость с устройствами:
| Устройство | Совместимость | Примечание |
|---|---|---|
| **Xiaomi Watch 5** |  **100% Полная** | Идеальная калибровка под корпус и сенсоры |
| **Xiaomi Watch 2 / 2 Pro** |  **100% Полная** | Платформа Wear OS |
| **Любые часы Wear OS (Android 8.0+)** |  **Совместимо** | Samsung Galaxy Watch, Pixel Watch, TicWatch и др. |
| *Xiaomi Watch S3 / S1 / Band* |  *Не поддерживается* | Работают на HyperOS Vela / FreeRTOS (не поддерживают APK) |

## 🚀 Установка

Готовый подписанный файл находится в папке [`release/WatchThermometer.apk`](release/WatchThermometer.apk).

### Шаг 1. Включите отладку на часах (один раз)
1. На часах откройте **Настройки** ➔ **Об устройстве** (или *Система* ➔ *О часах*).
2. Найдите пункт **«Номер сборки»** и нажмите на него **7 раз подряд**, пока не появится надпись *«Вы стали разработчиком»*.
3. Вернитесь назад и зайдите в новый пункт **«Для разработчиков»**.
4. Включите:
   - **Отладка по ADB** (ADB debugging)
   - **Отладка по Wi-Fi** (Wireless debugging)
5. Часы покажут ваш IP и порт, например: `192.168.1.45:5555`.

---

### Как вывести температуру на циферблат (Complication):
1. На главном экране часов зажмите палец на вашем текущем циферблате на 2 секунды.
2. Нажмите кнопку **«Настроить»** (Кастомизация).
3. Коснитесь любого круглого или строчного слота, куда хотите поместить градусник.
4. В списке приложений выберите **«Термометр»**.
5. Теперь температура будет отображаться прямо на циферблате и обновляться в реальном времени! При нажатии на нее мгновенно откроется приложение.

---

### Вариант А: Установка с компьютера (в 1 клик)
> Часы и компьютер должны быть подключены к одной сети Wi-Fi.

- **Windows:** Запустите файл [`release/install.bat`](release/install.bat) и введите IP-адрес часов.
- **Linux / macOS:** В терминале выполните:
  ```bash
  chmod +x release/install.sh
  ./release/install.sh
  ```
- **Или вручную через консоль:**
  ```bash
  adb connect 192.168.1.45:5555
  adb install -r -d -g release/WatchThermometer.apk
  ```

---

### Вариант Б: Установка прямо со смартфона (без компьютера)
1. На смартфоне установите бесплатное приложение **Bugjaeger** или **GeminiMan Wear OS Manager** из Google Play.
2. Подключите смартфон и часы к одному Wi-Fi (или включите точку доступа на телефоне).
3. В приложении введите IP часов и подтвердите запрос на экране часов (*«Всегда разрешать с этого устройства»*).
4. Во вкладке **Packages / Установка APK** выберите скачанный [`WatchThermometer.apk`](release/WatchThermometer.apk).
5. Приложение появится в меню ваших часов!

## 🛠️ Сборка из исходников

Вы можете собрать проект любым удобным способом:

### 1. Через Python (быстрая сборка за 3 секунды):
Требуется установленный Android SDK.
```bash
python build.py
```

### 2. Через Gradle / Android Studio:
Откройте репозиторий в **Android Studio** или соберите в терминале:
```bash
./gradlew assembleRelease
```
Результат будет сгенерирован в `app/build/outputs/apk/release/`.
